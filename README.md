# PriceOracle

Predicts whether you should buy something on Amazon now or wait.

Built for a hackathon. Next.js frontend + Firebase functions + a python pricing model in `predictive-pricing-engine/`.

## Setup

```
npm install
npm run dev
```

You need API keys for context.dev, Firebase and Resend in `.env.local` (see `.env.example`).
